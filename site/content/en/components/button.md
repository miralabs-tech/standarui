---
title: Button
description: A native button with a loading state that keeps its width and announces itself
---

`Button` renders a native `<button>` by default and infers `nativeButton` from what is actually rendered, so a substituted link keeps the right semantics. While `loading` is on, activation is refused, the label keeps its width and `aria-busy` says so.
